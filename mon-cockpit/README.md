# 🖥️ Mon Cockpit

Un seul écran pour **organiser sa semaine sans se serrer** : l'agenda du jour, la
semaine et le mois **en un coup d'œil**. Pensé pour être posé sur le Bureau et lu
d'un regard (grands caractères), même avec des lunettes.

> Outil de **soutien à l'organisation**. Ce n'est pas un outil de performance :
> il n'y a pas de « retard », seulement des choses qui attendent leur moment.

## ✨ Ce qu'il fait

- **3 vues** : **Aujourd'hui** (agenda avec heures optionnelles), **Semaine** (7 jours), **Mois** (calendrier avec pastilles).
- **Une priorité par jour** mise en avant (le reste = bonus).
- **Imprévu / événement de vie** : un bouton qui ré-ajuste la journée en douceur
  (décaler à demain, ou alléger pour ne garder que la priorité) — *rien n'est perdu*.
- **Marge / tampon** visible sous chaque jour (activable).
- **Grands caractères 👓**, **confort dys**, **thème clair/sombre**.
- **Touche spirituelle** optionnelle (messages sakîna / niyya / tawakkul).
- **Sauvegarde** (export JSON).

## 🔒 Confidentialité & hors-ligne

- **100 % local** : toutes les données restent dans le navigateur de l'appareil
  (`localStorage`, clé `cockpit.souple.v1`). Rien n'est envoyé sur Internet.
- **PWA installable** + **hors-ligne** (manifeste + service worker). Aucune dépendance,
  aucun outil de build — polices système, pas de réseau.
- Icônes **sans aucune représentation humaine** (motif agenda).

## ▶️ Utilisation

Ouvrir `index.html` dans un navigateur récent. Pour l'avoir comme un logiciel :
menu du navigateur → **« Installer »** (ou « Ajouter à l'écran d'accueil » sur mobile).

## 🧭 Place dans l'écosystème

Décline l'esprit **« Le point du jour »** (universel d'abord, spirituel en option) côté
organisation. Candidat naturel à brancher dans le hub **Les Deux Jardins** (route `/cockpit`).
