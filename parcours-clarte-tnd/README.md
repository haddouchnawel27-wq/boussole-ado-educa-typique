# 🧭 Parcours Clarté TND — produit autonome (Educa Typique)

Espace de travail pour développer et commercialiser la **Boîte NeuroPed**
sous forme d'un produit autonome : **Parcours Clarté TND**, proposé
**avec ou sans accompagnement**, à destination des familles et des professionnels.

> Création originale : **Nawel Haddouch — Educa Typique**. Tous droits réservés.

