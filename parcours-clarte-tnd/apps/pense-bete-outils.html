🗺️ Mes parcours d'accompagnement type

👩 Nouvelle consultante adulte (Jannat Al Qalb)
  1. Avant séance 1 → Bilan TCC
  2. Séance 1 ou 2 → Boussole de l'Âme
  3. Séance 4-5 → Schémas (si pertinent)
  4. Toi en interne → Hub Questionnaires (anamnèse) → Décodeur SHIFA pour synthèse
🧒 Nouvel ado tout public (Educa Typique)
  1. Avant séance 1 → Profil Cognitif
  2. Si suspicion TND → Profil Neuro
  3. Séance 1-2 → Match Intérieur
  4. Fin séance 1 → Boîte à Secours
🌙 Ado musulman pratiquant (Tawhid Académie)
  1. Avant séance 1 → Profil Cognitif
  2. Si suspicion TND → Profil Neuro
  3. Séance 1-2 → Match Intérieur
  4. Fin séance 1 → Trousse de Secours ISL
🩹 Enfant 6-12 ans NEW
  1. Avant séance 1 → Profil Cognitif (avec aide parent)
  2. Fin séance 1 → Boîte à Bobo Émotionnel
  3. Si devoirs difficiles → Kit Devoirs Sans Crise au parent
  4. Suivi → Suivi 7 jours (dans Kit Devoirs)
