# 🌍 Mettre Boussole en ligne — guide pas à pas

_Pas besoin de connaissances techniques. ~1 minute._

## L'objectif
Obtenir une **adresse web** pour ouvrir Boussole sur n'importe quel
téléphone, tablette ou ordinateur (et l'installer comme une application).

## Les étapes

1. **Ouvrir la page des réglages Pages.** Cliquez sur ce lien (ou copiez-le
   dans votre navigateur) :
   👉 https://github.com/haddouchnawel27-wq/boussole-ado-educa-typique/settings/pages

   _(Il faut être connectée à votre compte GitHub.)_

2. Vous voyez un encadré **« Build and deployment »**.
   - Ligne **« Source »** : laissez ou choisissez **« Deploy from a branch »**
     (= « Déployer depuis une branche »).

3. Juste en dessous, ligne **« Branch »**, deux menus déroulants apparaissent :
   - 1er menu : choisir **`claude/gracious-davinci-t0zife`**
   - 2e menu : choisir **`/ (root)`**
   - Cliquer le bouton **« Save »** (Enregistrer).

4. **Attendre 1 à 2 minutes.** Rafraîchissez la page : un bandeau vert
   apparaît avec l'adresse de votre site.

## 🎉 Votre adresse sera :
**https://haddouchnawel27-wq.github.io/boussole-ado-educa-typique/**

## 📱 Pour l'installer comme une application
Ouvrez cette adresse sur le téléphone/tablette → menu du navigateur →
**« Ajouter à l'écran d'accueil »**. Boussole apparaît comme une app et
fonctionne même sans connexion.
