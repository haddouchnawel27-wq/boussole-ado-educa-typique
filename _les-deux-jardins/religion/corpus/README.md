## Structure (exploitable directement)
Introduction → Bienfaits → Mode d'emploi (5 étapes) → **Fiches des 99 Noms**.
Chaque fiche suit **un format constant** :
`Nom (arabe + translittération) · Signification (aqîda) · 📖 Références (Coran) ·
💡 Effets psychologiques · ✨ Fruits spirituels · 🧠 Distorsions à corriger ·
🎯 Quand l'invoquer · 📿 Invocation (du'ā) · 🧩 Exercice thérapeutique · ⚠️ Piège`.

Chaque Nom = **une boussole** (du'ā + micro-action). Principe posé : *« la guérison vient
d'Allah ; les moyens sont des causes »* → cadre non-négociable déjà respecté.

## → Ce que ça alimente dans le produit
- **Module « Thérapie des Noms »** (mode islamique) : la praticienne choisit 1-2 Noms selon
  l'état de l'accompagnée → fiche sourcée + du'ā + exercice → **assignable** depuis la
  Bibliothèque du cockpit.
- **Encadré « boussole »** de la synthèse « Pour toi » : peut puiser un Nom + son du'ā (sourcé).
- **Équivalent mode universel** : les « Effets psychologiques » / « Exercice » se déclinent en
  version laïque (régulation, ancrage) — SANS le contenu confessionnel.

## ⚠️ Points à valider avec Nawel (avant toute publication)
1. **Nom du cabinet** : le corpus dit *Cabinet « Kanz-Al-Qalb »* (كنز القلب) ; la marque est
   *Jannat al Qulûb* (جنة القلوب). Harmoniser ?
2. **« Répète 7 jours »** (mode d'emploi) : présenté comme *constance* (habitude), pas comme
   chiffre rituel — confirmer que la formulation convient (rappel : « pas de chiffres rituels
   sans dalil »).
3. **Statut de publication** : chaque fiche reste `brouillon` tant que Nawel ne l'a pas validée.
